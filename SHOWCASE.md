# Showcase - people who finished the bootcamp

This is the board. Everyone here started from zero, ran all 11 missions, and shipped real work with Claude Code. Add yourself when you finish.

## How to get on the board (your last git rep)

You do not need to clone anything or use the terminal. Do it right from the browser:

1. Open this file (`SHOWCASE.md`) on GitHub.
2. Click the **pencil (edit) icon** in the top right.
3. Add one row to the table below (copy the format).
4. Click **Commit changes**, then **Propose changes**. GitHub automatically makes your own copy and opens a **pull request** back here.
5. That pull request is your graduation. When it is merged, you are on the board.

Prefer to do it with Claude Code? Ask your mentor: "help me open a pull request to add me to the bootcamp showcase." It will walk you through it with the `gh` tool.

Keep your row to one line. Link your own repo or your live MVP if you have one - that is your portfolio.
