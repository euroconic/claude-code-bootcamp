# Session 1 - Context, Agent vs Chat, Plan - Build - Check

**Theme of the live session:** an AI agent is not a smarter chat window. A chat answers from what you paste into it. An agent opens your files, does the work on your disk, and shows you the result. That only works well if you give it context (what the company is, what the files are, what "done" looks like) and follow one habit: **plan first, then build, then check against the source.**
