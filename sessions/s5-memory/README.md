# Session 5 - Memory and Your Working System

## Theme of the live session

How an agent remembers, in plain words. Four layers:

- **The chat is a whiteboard.** Everything on it is wiped when the meeting ends. Useful while you talk, gone tomorrow.
- **The memory file is the team handbook.** A short file the agent reads at the start of every session: who is who, where things live, house rules. Write a rule once, it applies every time.
- **Skills are recipe cards.** A saved method for one job (you built these in session 2).
- **Files are the archive.** The real results: reports, spreadsheets, notes. They stay on disk, and the agent can read them again.

Rule of thumb: if you find yourself explaining the same thing to the agent twice, it belongs in the handbook. If you find yourself repeating the same job, it belongs on a recipe card.
