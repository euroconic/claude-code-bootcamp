# Bonus - Documents as Agent Knowledge

## Theme of the live session

Your company already has the answers: in policies, procedures, and manuals. People still ask the same questions every week because nobody wants to read 40 pages. This bonus shows how to give an agent a folder of documents and ask it questions, with one strict rule: **it answers only from the documents, shows where it found each answer, and says "not in the sources" when it cannot find one.**

You also build a **read-only helper**: an agent that is allowed to read and search, but not to write or change anything. Think of a librarian who can find the book for you but is not allowed to edit it.
