# Bonus - Roles and Automation

## Theme

Two things in one bonus folder. First, practice for the project roles: a project manager who has to see trouble coming, and a technical project manager who has to see who is waiting on whom. Both work on the same project you already know, the supplier discrepancy tool. Second, make an agent work without you: a report that runs by itself, and (optionally) arrives in your Telegram.

The rule from the whole track still holds: the agent works only from the files you give it, and every fact in your output must be in those files. If something is missing, the output says "not in the notes" instead of guessing.

## Missions

| Mission | What | Time | Core? |
|---|---|---|---|
| 7A | Project Manager: pre-mortem and a status report from raw notes | 35 min | Bonus |
| 7B | Technical Project Manager: dependency map and release risks | 35 min | Bonus |
| 7C | Proactive agent: the Friday report runs by itself | 35 min | Bonus (needs 3B first) |
| 7D | Telegram bot that delivers the report | 40 min | Optional bonus (needs 7C, and a personal Telegram account) |

Data: `data/corvane/s7/` (a project plan, raw weekly notes, a release plan, and a teams note). Output goes to `workspace/work/`.

## Practice by your role

Not every mission fits every job. Start where your job is:

- **Business Analyst:** 2C, 4A, 4B (then 7C if you have a weekly report of your own).
- **Project Manager:** 3B, 7A.
- **Technical Project Manager:** 7B, 4C.
- **Product Manager:** the Signal track, missions 03 to 08.

7C and 7D are for everyone who has a weekly report or a question people ask again and again.
