# Quick Guide - Get This Project (2 minutes)

You do not need a GitHub account, and you do not need to know what GitHub is, to get a copy of this course onto your computer. This guide gets you there. If you already have the folder, skip to [START-HERE.md](START-HERE.md).

> In one sentence: **GitHub** is a website where this project's files live. You are just visiting that website once to download a copy, the same way you would download a PDF or a photo.

---

## Step 1 - Go to the project's page

Open this link in your browser: https://github.com/euroconic/claude-code-bootcamp

You will see a page listing folders and files, things like `START-HERE.md` and `missions`. That is this same course, just viewed on the website instead of on your computer.

---

## Step 2 - Download it as a zip (no account needed)

1. Near the top of the page, find the green button that says **`< > Code`**. Click it.
2. A small menu drops down. Click **Download ZIP** (near the bottom of that menu).
3. Your browser downloads a file, usually to a folder called **Downloads**.

That is the whole download. No sign-up, no login.

---

## Step 3 - Unzip it

A zip file is a folder squeezed down for downloading, you need to "unzip" it once before you can use it.

- **Mac:** find the downloaded file (probably `claude-code-bootcamp-main.zip` in your Downloads folder) and double-click it. It unpacks into a regular folder right next to it.
- **Windows:** right-click the downloaded zip file and choose **Extract All...**, then click **Extract**. It unpacks into a regular folder.

Move that unpacked folder somewhere you will find it again, your Desktop is a fine choice.

---

## Step 4 - You have the project

Open that folder and confirm you see files like `START-HERE.md`, `CLAUDE.md`, and a `missions` folder inside. If so, you are ready.

Head to [START-HERE.md](START-HERE.md) and follow it from there (it will have you install Claude Code if you have not already, then open this folder and type `begin`).

---

## (Optional, more advanced) Get your own copy as a GitHub repo

If you already have, or want, a free GitHub account, there is a second way that also gives you a place to save your work as you go and show it off later (this matters for Mission 09 and the Capstone).

1. Sign up for a free account at https://github.com if you do not have one.
2. Go back to https://github.com/euroconic/claude-code-bootcamp and click the green **Use this template** button near the top of the page.
3. Give your copy a name and click **Create repository**. GitHub makes you your own copy of this whole project, under your account.
4. From there, use GitHub's green **`< > Code`** button on *your* copy and download it the same way as Step 2 above, or, if your mentor walks you through it in Mission 09, you can also have Claude Code pull it down for you directly.

If that sounds like too much right now, the plain zip download in Steps 1-4 above is all you need to start. You can always come back to this later.
