# Claude Code Bootcamp

**A Claude Code Bootcamp by [AIsandboxlab.com](http://AIsandboxlab.com).**

A self-paced bootcamp where **Claude Code itself is your mentor**. Open this folder in Claude Code, type `begin`, and it walks you through 11 core missions plus two optional bonus stops, on one continuous case - from a fuzzy startup idea to a shipped MVP. No coding background needed.

Built for product managers, business analysts, designers, founders, and marketers.

## Start here

1. **Install Claude Code** if you have not: see [INSTALL.md](INSTALL.md) (5-10 minutes from zero).
2. **Get this project**, one of two ways:
   - Click **Use this template** (green button, top of the GitHub page) to get your own copy as a repo, or
   - Download it as a zip and unzip it somewhere you can find.
3. **Open the folder in Claude Code** (terminal, VS Code, or the Claude desktop app) and type `begin`.

Full walkthrough: [START-HERE.md](START-HERE.md).

## What you build

Your own AI agent, a market-research brief, a data-insights report, a decision memo, a prioritized backlog, a full PRD, and a working MVP landing page you can ship live. See [THE-CASE.md](THE-CASE.md) for the story you operate in.

## When you finish

Add yourself to [SHOWCASE.md](SHOWCASE.md) (it doubles as your last git rep), then bring your work into the **AI Native Sandbox** community to keep going on your real job.
