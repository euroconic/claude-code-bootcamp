# Feature list: Supplier Discrepancy Tool

F-1. Compare invoice lines with purchase-order lines on quantity and unit price.

F-2. Tolerance: a difference below 1% of the line value is accepted automatically.

F-3. One shared screen listing all discrepancies for the pilot suppliers.

F-4. Status for each discrepancy: Open, Accepted, Disputed.

F-5. Dispute approval: a dispute is approved by the reconciliation lead before the supplier is contacted.

F-6. Comment trail on every discrepancy.

F-7. Export of the discrepancy list as a CSV file for the monthly report.
