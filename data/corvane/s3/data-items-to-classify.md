# Data Items to Classify (Corvane, session 3)

Fictional. Corvane IT will connect the task tracker and the ERP to the AI working group's agent soon, and wants a one-page safe-use note first. These are twelve kinds of data the working group might want to give the agent. Sort each one into a color for the note in mission 3C.

| # | Item | Where it lives | What is in it |
|---|---|---|---|
| 1 | National Bank of Poland daily exchange-rate table | Public website | Published rates, same for everyone |
| 2 | Corvane product catalogue (the PDF sent to customers) | Public website and sales emails | Product names, pack sizes, list prices, no customer data |
| 3 | Folder of Corvane policies (travel, expenses, supplier onboarding) | Shared drive, folder "Policies" | Internal rules, no names of private persons, nothing marked confidential |
| 4 | Draft requirements document for the discrepancy tool | Shared drive, folder "Project Office" | Business rules and screens, no personal data, no prices |
| 5 | Task-tracker export with change requests | Tracker, "Export" button | Ticket titles, status, dates, and the full name of the person who owns each ticket |
| 6 | Purchase-order export from the ERP | ERP, nightly export file | Supplier names, product codes, quantities and the prices Corvane negotiated |
| 7 | Scanned supplier invoices (PDF) | Accounts-payable mailbox | Supplier name, items, totals, and the supplier's bank account number at the bottom |
| 8 | Transcript of a 40-minute project call | Meeting recording tool | Project talk, plus first names and a few remarks about how colleagues work |
| 9 | Customer file from the sales system | Sales system export | Hotel and restaurant names, plus phone numbers and home addresses of sole-trader owners |
| 10 | Salary and bonus table for the warehouse team | HR drive | Names, pay, bonus amounts |
| 11 | A text note a colleague keeps with the tracker's access token | Colleague's desktop | The token itself: a long code that works like a password for programs |
| 12 | Signed supplier contract currently in a legal dispute | Legal department folder | Prices, penalties, signatures, lawyer comments |

Colors for the note:

- **Green:** ok to give the agent.
- **Amber:** only after it has been anonymized or trimmed (names, numbers, or columns removed), and only if IT has approved the tool for company data.
- **Red:** never goes to an agent.
